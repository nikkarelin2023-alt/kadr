# SQLite и вход по коду

Требуется Node.js 24+ и установка зависимости: npm install (или pnpm install --frozen-lockfile).
Запуск: npm start. База создаётся автоматически в data/kadr.sqlite, миграции — migrations/*.sql.
Для другого пути задай DATABASE_PATH. Весь каталог базы должен быть на постоянном локальном диске.

## Вход по почте

Supabase больше не используется. В .env.local заполни SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS и SMTP_FROM.
Порт 587 использует обязательный STARTTLS, порт 465 — TLS с начала соединения. Проверка сертификатов включена.
Используй данные выбранного почтового провайдера, при необходимости пароль приложения.
Никакие реальные письма без этих настроек не отправляются. Коды не выводятся в логи или ответы API.
После настройки перезапусти сервер и нажми «Войти». Код из 6 цифр действует 10 минут, допускается 5 неверных попыток.
Гостевой список можно перенести в аккаунт по кнопке после входа; старые локальные списки не удаляются.

## Хранение

В SQLite находятся users, email_codes, sessions, user_items, rate_limits и schema_migrations.
Сессионные токены хранятся только в виде SHA256-хешей; коды — scrypt-хешей с отдельной солью.
Доступ к коллекции ограничивается сервером через ID владельца из сессии, а не из запроса клиента.
Файл базы не раздаётся HTTP-сервером и исключён из Git и Docker-образа.
SQLite — серверная база: на телефон или в iOS-приложение этот файл не передаётся.

## Проверки

npm test
npm run backup

Настройка сервера и резервирования — DEPLOYMENT.md. Реальные SMTP-письма ещё требуют проверки с твоим провайдером.

## Gmail для локальной проверки

Сервер smtp.gmail.com, порт 465 (TLS). В SMTP_USER и SMTP_FROM укажи один и тот же полный адрес Gmail. В SMTP_PASS вставь пароль приложения, созданный в https://myaccount.google.com/apppasswords после включения двухэтапной аутентификации. Название приложения: Кадр. Пробелы в пароле приложения Gmail удаляются автоматически.
Проверка без отправки писем: npm run smtp:check. После успешной проверки перезапусти сервер и запроси код через кнопку «Войти».
