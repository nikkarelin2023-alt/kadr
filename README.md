# Кадр

Подбор фильмов и сериалов по настроению, жанрам, странам, периодам и рейтингу. Свайпы с отменой, поиск, личные списки и оценки.

## Запуск

Нужен актуальный Node.js 24+.

```sh
npm install
cp .env.example .env.local
npm start
```

В Windows файл настроек можно скопировать через Проводник. Заполни TMDB_READ_TOKEN. Адрес: http://localhost:8080; с телефона — IP компьютера в той же сети Wi-Fi.

## Аккаунты и SQLite

База создаётся автоматически в data/kadr.sqlite; миграции применяются при запуске. Для email-кодов нужен SMTP. Гостевую коллекцию можно перенести после входа.

Настройка: [SQLITE_SETUP.md](SQLITE_SETUP.md).

## Сервер

Подготовлены Dockerfile, Compose, постоянные volumes, /api/health и согласованные резервные копии SQLite.

Инструкция: [DEPLOYMENT.md](DEPLOYMENT.md). Это конфигурация одного сервера с постоянным локальным диском. Для нескольких хостов потребуется PostgreSQL.

```sh
npm test
npm run backup
```

Тесты используют реальную временную SQLite и тестовую доставку писем. Gmail SMTP и вход проверены пользователем локально. Docker и доставку писем на целевом сервере ещё нужно проверить. База, сессии, бэкапы и секреты не входят в Git.
