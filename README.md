# Кадр

Прототип помощника по выбору кино на русском языке. Откройте `index.html` в браузере. Установка зависимостей не требуется.

Опрос по настроению, длительности и жанру; карточки с горизонтальными свайпами и кнопками; списки «Хочу посмотреть» и «Просмотрено»; оценки просмотренного. Данные хранятся в localStorage браузера.

Каталог демонстрационный (16 фильмов). Иллюстрации типографические, не официальные постеры. Подбор сортирует подходящие по длительности и жанру фильмы по совпадению настроения. Авторизация, синхронизация, внешний каталог и обучение на оценках пока не подключены.

Следующий этап: перенос интерфейса в Next.js / TypeScript, подключение Supabase Auth и таблиц пользовательских списков, затем API каталога.

Опрос расширен до пяти шагов: настроение, время, жанр, эпоха и компания. Семейная подборка задана вручную; возрастной рейтинг нужно проверять отдельно.

Добавлен шестой шаг: фильм, сериал или любой формат. В каталоге 16 фильмов и 4 сериала; для сериала фильтр времени применяется к примерной длительности серии. Подпись свайпа влево расположена справа, свайпа вправо — слева.

Реальный API: /api/catalog загружает 4 сериала из TVmaze (CC BY-SA), кеширует на час. Запуск: node server.cjs. В Windows запросы выполняются через PowerShell с системными сетевыми настройками. Фильмы остаются демонстрационными. Описания TVmaze на английском. Статус Ended означает окончание выхода, а не гарантию завершённого сюжета. При сбое API остаётся тестовый каталог.

Каталог расширен: первая страница TVmaze (проверено: 240 сериалов). Сезоны загружаются по запросу при показе карточки через /api/seasons/:id и кешируются. Описание сокращается до 180 символов по предложению или границе слова; полный текст доступен в раскрывающемся блоке. Это сокращение исходного текста, не ИИ-пересказ. Постер и отступы уменьшены для мобильного экрана.

Отмена действий: кнопка над карточкой возвращает предыдущий вариант и отменяет добавление в соответствующий список. Можно отменять несколько действий подряд в текущей подборке, в том числе после последней карточки. При новом подборе история сбрасывается. Первый вопрос расширен до 6 настроений; комедия и напряжение учитывают жанровые теги.

Подготовка TMDB: открой .env.local и вставь API Read Access Token после TMDB_READ_TOKEN= без слова Bearer. Файл исключён из Git и не раздаётся сервером. После изменения потребуется перезапуск сервера. Чтение настроек подготовлено; интеграция каталога TMDB ещё не подключена.

Подбор по условиям: /api/discover?format=series&genres=mystery&rating=7&ended=1&page=1. Пять экранов опроса в discovery.js, API в discover.cjs. Не задаём время и возрастной рейтинг. TMDB допускает до 500 страниц на запрос; новые условия начинают новую подборку. При сетевой ошибке доступна повторная загрузка с сохранением условий.

Настроение и фильтры: единые правила в catalog-rules.js. Это явная эвристика по жанрам, а не анализ эмоционального содержания. Порог нехватки — меньше пяти оставшихся карточек после исчерпания страниц текущих условий. Ослабление: рейтинг → жанры → периоды → настроение; формат/завершённость не ослабляются. Списки фильтруются строго и не изменяются фильтрацией. Персональные коррекции хранятся в браузере.
Поиск: /api/search?q=название&page=1, раздел «Поиск» в интерфейсе; значения передаются в API безопасно через переменные окружения дочернего процесса. Автотесты: node test-catalog.cjs.

Учётные записи: см. SUPABASE_SETUP.md. Код входа и синхронизации подготовлен, требуется настройка проекта Supabase. Публичный ключ и URL задаются в .env.local; service_role не нужен. Автотесты: node test-account.cjs, node test-auth-client.cjs, node test-catalog.cjs. Для публикации остаётся заменить Windows-адаптер сети, настроить HTTPS и продакшен-параметры.
