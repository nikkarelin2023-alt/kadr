Проверки: node --check для JS и сервера; API каталога вернул 240 записей, сезоны Breaking Bad — 5. Логика отмены save/watched/skip проверена через Node VM. Полной визуальной автоматической проверки не было; пользователь подтвердил работу свайпов на телефоне.

Новый этап: discovery.js и discover.cjs добавляют запросы /api/discover по ответам и подгрузку страниц. Пять экранов: формат, настроение, жанры (OR), исключения, общий экран дополнительных настроек (период/рейтинг/завершённость). Вопросы времени и компании удалены из активного опроса, возрастные ограничения не задаются. Рейтинг требует минимум 100 голосов. Только завершённые: with_status=3, Canceled исключён. Подгрузка не сбрасывает очередь и историю отмен. TVmaze остаётся старым маршрутом для старых карточек; автоматической замены строгой подборки TVmaze нет. Жанры TV ограничены словарём TMDB, объединённые категории отмечены в интерфейсе. Проверены реальные две страницы completed mystery >=7, логика очереди/отмены в VM; визуально новый опрос нужно оценить пользователю.

Рейтинг обновлён: по умолчанию выключен переключатель «Учитывать рейтинг». При включении ползунок 0–9 с шагом 0,5, начальное значение 7,0. При выключении значение сохраняется в текущей сессии. API получает ratingEnabled отдельно от rating; выключение убирает и порог оценки, и 100 голосов, включение применяет оба даже при пороге 0. Проверены переключение и сохранение значения, запрос TMDB >=7,5 вернул 20 фильмов без нарушений порога.

ОС первых пользователей: один экран жанров, все 14 выбраны по умолчанию. Любые жанры переключает все/ничего; пустой выбор блокирует следующий шаг. Отключённые жанры отправляются как исключения. Четыре экрана опроса. Периоды многозначные: сервер строит непрерывный диапазон min–max с промежутками; пояснение есть в UI. Персональная обратная связь по метке настроения хранится в state.moodCorrections по ID и настроению в localStorage: убирает позитивную подпись, даёт score=-1 при следующих подборках, есть отмена. Не обобщается на жанры или других пользователей. Проверены переключения жанров, пустой выбор, периоды, изоляция поправки по настроению и реальные фильтры API.

Исправление ОС: выбранные периоды теперь отдельные интервалы, без промежуточных лет. Сервер создаёт запросы по каждому интервалу; проверено zero,new — 40 фильмов без 2010–2019. Мобильный экран карточек: класс swipe-screen, фиксированный viewport 100dvh, safe area, flex-компоновка карточки и кнопок, без прокрутки body. touch-action:pinch-zoom на карточке, вертикальное отклонение в начале больше не отменяет свайп, отпускание проверяет преобладание горизонтали. Длинное описание открывается dialog с отдельной прокруткой. Проверены синтаксис, интервалы API и диагональный жест в VM. На реальном iPhone после этих изменений ещё не проверялось.

Доработки подборок: catalog-rules.js объединяет числовые жанровые правила настроений и пересечение всех фильтров. Посмеяться требует Comedy и исключает Drama/Horror/Thriller. Проверяются выбранные жанры, исключения, даты, точный рейтинг и голоса на клиенте после API. При исчерпании текущего уровня и остатке <5 карточек снимаются ограничения по порядку: рейтинг, жанры (включая исключения), период, настроение. Уровень записан у карточки, отмечается в сводке; формат и завершённость остаются строгими. Персональные коррекции исключают совпадение до этапа снятия настроения. Кнопка обратной связи доступна на каждой карточке; нажал/отменил в UI — проверено.
Поиск: вкладка «Поиск», /api/search, поиск по названию TMDB с пагинацией и сохранением в saved/watched без дублей. collection.js добавляет независимые строгие фильтры списка «Хочу посмотреть» и обновляет метаданные старых TMDB-сохранений через API.
