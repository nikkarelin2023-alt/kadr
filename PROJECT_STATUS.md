# Кадр — текущее состояние

Стек: Node.js 24+, HTML/CSS/JS, TMDB, SQLite (node:sqlite), Nodemailer. Supabase заменён; пользователь ещё не создавал в нём аккаунты, облачных данных для переноса нет.

Работает подбор по пересечению фильтров, поиск, свайпы с отменой, сводка и поправки настроения. Периоды независимые; только вышедшие релизы. При исчерпании результатов ослабляются рейтинг → жанры → период → настроение. Страна/формат/завершённость остаются. Список «Хочу посмотреть» имеет отдельный редактор с Применить/Отмена; сброс на результатах.

Аккаунты: email-код 6 цифр, 10 минут, пять попыток. Сессии 30 дней. SQLite хранит пользователей, хеши кодов и сессий, коллекции, оценки, поправки и лимиты. Гостевые данные сохраняются, импорт по кнопке после входа. Владелец записей определяется только сессией.

Сервер: SQLiteRepository, WAL/FULL/foreign keys/busy timeout, атомарные миграции и пакеты изменений, индексы, backup API, healthcheck, закрытие БД при остановке. Docker/Compose с постоянным диском и пользователем node. Linux использует fetch; Windows — системный сетевой адаптер. SMTP через Nodemailer. Инструкции: SQLITE_SETUP.md и DEPLOYMENT.md.

Ограничения: один экземпляр приложения на одном сервере; для нескольких хостов нужны PostgreSQL и миграция репозитория. Docker не установлен в текущей среде, образ здесь не запускался. Gmail SMTP настроен локально; пользователь подтвердил реальную доставку кода и вход. Внешний сервер не развёрнут.

Тесты: test-account.cjs проверяет реальную SQLite, миграции, перезапуск, backup/restore, изоляцию двух пользователей, rollback, OTP/replay/попытки и CSRF. Тесты клиента и каталога сохранены. data/kadr.sqlite и бэкапы исключены из Git/Docker.
